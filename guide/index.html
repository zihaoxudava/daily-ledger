日常账本使用手册

iPhone 安装、离线记账、预算与换机

打开日常账本

安装到 iPhone 主屏幕

  1. 用 Safari 打开上方链接即可使用日常账本。
  2. 轻点「共享」→「添加到主屏幕」。如果页面菜单收起了「共享」，先点页面菜单。看到「作为网页 App 打开」时将其开启，然后轻点「添加」。
  3. 回到主屏幕，从「日常账本」图标联网打开一次。等顶部显示「离线可用」后再断网测试。
  4. 可用飞行模式测试。开启后退出账本，从主屏幕图标重新打开并试记一笔。到「明细」核对，再删掉测试账目。

请在主屏幕版建立正式账目。Safari 标签页与主屏幕版的本机数据可能各自保存，可以通过 JSON 备份迁移。

记一笔与查明细

  1. 轻点底部「记一笔」，或在总览使用「支出」「收入」「转账」「退款」。填写金额、账户、日期和适用的分类，时间和备注可选。
  2. 「明细」顶部有「账户转账」。选转出和转入账户即可，例如银行卡转入支付宝。转账只改变账户余额。信用卡消费记支出，还款用转账转入信用卡。
  3. 收到商家退款时选「退款」，用原支出的分类和实际收款账户，日期填到账日。当月净支出会扣减这笔退款。
  4. 在「明细」按月份、类型、账户和分类组筛选，也能搜索备注或金额。点一条账目可编辑或删除，导出按钮只导出当前筛选结果。
  5. 轻点页面顶部的年月进入「月份总览」，用左右按钮换年。轻点某个月份即可返回原页面并切换到该月。

批量记录同一天

  1. 从总览或明细点「批量记账」，也可以从「记一笔」窗口切过去。已经填写的日期和第一笔内容会一起带过去。
  2. 在顶部选一次「统一日期」。填好金额、类型、账户和分类，需要更多记录就点「再加一笔」。新一笔会带入上一笔的类型和账户，时间可逐笔选填。
  3. 核对日期和笔数，点「保存 N 笔」，整批账目会一次保存。有一笔未填完整时，补齐或移除此笔后再保存。

账户与分类

  • 「更多」→「账户」可以新增账户、改名和填写期初余额。期初金额填开始记账前的余额，已有信用卡欠款可填负数。余额按今天及以前的账目累计，归档账户的历史和余额仍保留。
  • 「更多」→「分类」下分支出和收入。展开分类组可添加二级分类、改名或归档分类。默认有餐饮、交通、校园、住房、项目和健康等分组。
  • 记账时点分类栏旁的「＋ 添加分类」，填写名称并选分类组。点「保存并选用」可继续填写当前账目，也适用于批量记账。

预算、周期账单与统计

  • 在总览点「设置预算」，或进入「更多」→「预算与周期」→「本期预算」。总预算和分类组预算各自显示使用进度。同一月同一范围只能设一项，换月可设置新的预算。
  • 在「预算与周期」→「周期账单」新增每周、每月或每年的固定收支。可用总次数或截止日期结束规则，适合订阅、房租、工资和分期。首次日期若在过去，符合条件的到期账目会在保存时一并补记。
  • 周期账单在打开 App 或回到前台时入账。暂停后再启用会从下一期继续。删除规则会保留已生成的账目。每月 31 日的规则遇到短月会在该月最后一天入账。
  • 「统计」支持按月或按年，查看收入、净支出、结余和分类占比。结余等于选定期间的收入减净支出。转账只改变账户余额。

借出、借入与还款

  1. 从手机底部轻点「借出借入」，按实际情况点「新增借出」或「新增借入」，填写称呼、本金和日期。借款、收款和还款都可选填时间。
  2. 点开一项借款，通过「记收款」或「记还款」登记每次归还的金额。剩余金额归零时显示「已结清」。点一笔还款记录可以修改或删除。
  3. 借款和还款在此处单独查看，总账收支、预算和账户余额按主账单计算。换机时用完整 JSON 备份一起迁移。

备份、恢复与 CSV

  1. 换机或卸载前备份。去「更多」→「数据与备份」→「导出完整备份」，把 JSON 保存到 iPhone「文件」或你选的备份位置。
  2. 恢复完整账本。在目标设备打开同一 App，轻点「恢复备份」，选 JSON，核对笔数后确认。恢复会覆盖目标设备已有的账本。
  3. 导入流水。下载 CSV 模板，保留表头，保存为 UTF-8 CSV。日期用 2026-11-23 格式，时间可填 18:30 或留空。金额填正数，类型填「支出」「收入」「转账」或「退款」。转账填写转入账户并将两列分类留空，其余类型填分类组和分类，转入账户留空。
  4. 避免重复。由本 App 导出的同一笔账目的记录编号保持一致，重复导入会跳过。自己填模板时可用唯一编号；留空会按新账目导入。CSV 用于流水，完整的预算、规则和期初余额请用 JSON。

常见问题

  • 看不到离线可用。在主屏幕版保持联网，关闭后重新打开，确认已进入账本页面。安装或更新时需要联网。
  • 主屏幕打开还是旧版。保持联网，从已有的「日常账本」图标打开，稍等片刻，再从 App 切换器关闭并打开一次。进入新版后，可从顶部「离线可用」或「更多」里的「iPhone 安装与离线」查看版本并检查更新。出现「新版已就绪」时，点「立即更新」。
  • 查看更新内容。打开新版时，点页面顶部的「查看更新」，也可随时从「更多 → 版本更新」查看历次改动。
  • 另一台设备看不到记录。数据保存在当前设备的网页 App 中，通过导出和恢复 JSON 迁移。删除网页 App 或清理站点数据可能导致本地记录丢失。
  • 微信或支付宝账单导入失败。先将账单列整理成本 App 的 CSV 模板格式。应用不读取平台账号或银行卡数据。
