打开日常账本

安装到桌面或主屏幕

三星及安卓独立版。下载并打开 APK，按系统提示安装。旧网页账本请先导出完整 JSON，再在 App 的「更多 → 数据与备份」中恢复。联网启动时顶部会提示可用更新，下载后覆盖安装即可。下载 Android 安装包

用系统浏览器打开账本，再到「更多 → 安装到桌面」。看到「安装日常账本」时可以直接点。也可以按设备使用浏览器菜单。

  • iPhone / iPad。用 Safari 点「共享 → 添加到主屏幕」。看到「作为网页 App 打开」时将其开启。Apple 指南
  • 安卓手机和平板（含三星）。用 Chrome 打开右上角菜单，选「安装应用」或「添加到主屏幕」。Chrome 指南
  • 三星自带浏览器。在 Samsung Internet 点地址栏的安装图标，按提示安装。也可以在菜单里将网页添加到主屏幕。若图标先出现在应用列表，长按图标即可添加到主屏幕。三星安装指南
  • Windows / Linux / Chromebook。在 Chrome 地址栏点安装图标，或在菜单选「投放、保存和分享 → 将网页安装为应用」。Windows 也可用 Edge 菜单「应用 → 将此站点作为应用安装」，再从 edge://apps 建立桌面快捷方式。Chrome 指南 · Edge 指南
  • Mac。macOS 14 及以上可在 Safari 选「文件 → 添加到程序坞」，也可用 Chrome 安装。Apple 指南

从新图标联网打开一次，等页面显示「离线可用」。换设备或从另一浏览器迁移账目时，请导出完整 JSON 后在目标账本恢复。

华为／鸿蒙设备

HarmonyOS 5 及以上，用华为浏览器打开账本，点网页菜单「∷ → 添加至桌面」，确认后就能从桌面打开网页版。能安装 APK 的华为设备也可以使用 Android 安装包。

记一笔与查明细

  1. 轻点底部「记一笔」，或在总览使用「支出」「收入」「转账」「退款」。填写金额、账户、日期和适用的分类。时间默认「不填」，可点「设置时间」。已选时间时可点「不填」清除。
  2. 备注旁点「照片」或「文件」可添加附件。每笔最多 6 个，文件大小和总量由设备空间与系统存储配额决定。保存后可重新打开账目，预览照片或保存原文件。
  3. 「明细」顶部有「账户转账」。选转出和转入账户即可，例如银行卡转入支付宝。转账只改变账户余额。信用卡消费记支出，还款用转账转入信用卡。
  4. 收到商家退款时选「退款」，用原支出的分类和实际收款账户，日期填到账日。当月净支出会扣减这笔退款。
  5. 在「明细」按月份、类型、账户和分类组筛选，也能搜索备注或金额。点一条账目可编辑或删除，导出按钮只导出当前筛选结果。
  6. 在明细列表的「账目」旁点「多选」，勾好要改的记录，再点「批量改时间」。日期和具体时间可分别修改，也可批量清除具体时间。
  7. 轻点页面顶部的年月进入「月份总览」，用左右按钮换年。轻点某个月份即可返回原页面并切换到该月。

批量记录同一天

  1. 从总览或明细点「批量记账」，也可以从「记一笔」窗口切过去。已经填写的日期和第一笔内容会一起带过去。
  2. 在顶部选一次「统一日期」。填好金额、类型、账户和分类，需要更多记录就点「再加一笔」。新一笔会带入上一笔的类型和账户，时间可逐笔选填。
  3. 核对日期和笔数，点「保存 N 笔」，整批账目会一次保存。有一笔未填完整时，补齐或移除此笔后再保存。

账户与分类

  • 「更多」→「账户」可以新增账户、改名和填写期初余额。期初金额填开始记账前的余额，已有信用卡欠款可填负数。余额按今天及以前的账目累计，归档账户的历史和余额仍保留。
  • 「更多」→「分类」下分支出和收入。展开分类组可添加二级分类、改名或归档分类。默认有餐饮、交通、校园、住房、项目和健康等分组。
  • 记账时点分类栏旁的「＋ 添加分类」，填写名称并选分类组。点「保存并选用」可继续填写当前账目，也适用于批量记账。

预算、周期账单与统计

  • 在总览点「设置预算」，或进入「更多」→「预算与周期」→「本期预算」。总预算和分类组预算各自显示使用进度。同一月同一范围只能设一项，换月可设置新的预算。
  • 在「预算与周期」→「周期账单」新增每周、每月或每年的固定收支。可用总次数或截止日期结束规则，适合订阅、房租、工资和分期。首次日期若在过去，符合条件的到期账目会在保存时一并补记。
  • 周期账单在打开 App 或回到前台时入账。暂停后再启用会从下一期继续。删除规则会保留已生成的账目。每月 31 日的规则遇到短月会在该月最后一天入账。
  • 「统计」支持按月或按年，查看收入、净支出、结余和分类占比。结余等于选定期间的收入减净支出。转账只改变账户余额。
  • 点分类行、支出圆环、月份趋势柱或汇总金额，查看该范围内的账单。净支出包含原支出和抵扣的退款。明细中点账目可编辑，再点「返回统计」回到图表。

定期存款

  1. 点总览顶部的「定期存款」卡片，可直接查看已存和累计待存。进入后点「新增计划」，填写每日应存金额和开始日期。结束日期可选。
  2. 账本按本机日期累计应存，打开时可补算过去的天数。实际存入后点「记存入」。少存的部分继续计入待存，补存后会扣减待存。不同计划分别计算。
  3. 「存款总量」是已记的实存金额，普通收支和账户余额分别计算。存款计划和记录会随完整 JSON 备份导出。

借出、借入与还款

  1. 从手机底部轻点「借出借入」，按实际情况点「新增借出」或「新增借入」，填写称呼、本金和日期。借款、收款和还款都可选填时间。
  2. 打开一笔未结清借款，点「设置提醒」，填写提醒日期和时间。安卓版请开启通知。需要准时提醒时，可在同一页面开启「允许准时提醒」。结清会取消安卓版的待发提醒。
  3. 网页和 iPhone 版保存后可点「下载日历提醒」，将事件添加到日历并确认提醒时间。也可在手机日历按显示的日期和时间手动创建事件。改期或结清时可以在日历里调整原事件。
  4. 点开一项借款，通过「记收款」或「记还款」登记每次归还的金额。剩余金额归零时显示「已结清」。点一笔还款记录可以修改或删除。
  5. 借款和还款在此处单独查看，总账收支、预算和账户余额按主账单计算。换机时用完整 JSON 备份一起迁移。

备份、恢复与 CSV

  1. 换机或卸载前备份。去「更多」→「数据与备份」→「导出完整备份」，把 JSON 保存到 iPhone「文件」或你选的备份位置。JSON 包含照片和文件，CSV 只包含流水和文字备注。
  2. 恢复完整账本。在目标设备打开同一 App，轻点「恢复备份」，选 JSON，核对笔数后确认。恢复会覆盖目标设备已有的账本。
  3. 导入流水。下载 CSV 模板，保留表头，保存为 UTF-8 CSV。日期用 2026-11-23 格式，时间可填 18:30 或留空。金额填正数，类型填「支出」「收入」「转账」或「退款」。转账填写转入账户并将两列分类留空，其余类型填分类组和分类，转入账户留空。
  4. 避免重复。由本 App 导出的同一笔账目的记录编号保持一致，重复导入会跳过。自己填模板时可用唯一编号；留空会按新账目导入。CSV 用于流水，完整的预算、规则和期初余额请用 JSON。

常见问题

  • 看不到离线可用。在主屏幕版保持联网，关闭后重新打开，确认已进入账本页面。安装或更新时需要联网。
  • 更新版本。在「更多 → 应用信息」或「更多 → 安装到桌面」可以看当前版本并手动检查更新。网页小更新会在空闲时应用，安卓小更新会自动下载，安装时按系统提示确认。大版本按顶部提示更新。
  • 查看更新内容。打开新版时，点页面顶部的「查看更新」，也可随时从「更多 → 版本更新」查看历次改动。
  • 联系开发者。在「更多」页底部可点手机号拨号，或点 QQ 邮箱发送反馈。
  • 另一台设备看不到记录。数据保存在当前设备的网页 App 中，通过导出和恢复 JSON 迁移。删除网页 App 或清理站点数据可能导致本地记录丢失。
  • 微信或支付宝账单导入失败。先将账单列整理成本 App 的 CSV 模板格式。应用不读取平台账号或银行卡数据。

Android 自动记账

  1. Android 安装版打开「更多 → 自动记账 → 配置自动记账」。选择目标账本，分别为微信和支付宝选好入账账户，勾选启用并保存。只想启用一个平台时，另一个选「关闭该平台」。
  2. 点「系统通知访问」，开启「日常账本自动记账」。若系统提示受限，请在系统应用信息中查看是否提供「允许受限设置」。仅为信任来源安装的日常账本授予权限。
  3. 保留支付 App 的付款通知。付款时符合条件的通知会记录在本机，打开日常账本后自动记为支出，可在明细中更改分类。

只有明确带金额的微信、支付宝付款通知才会进入账本。付款没有通知、金额被隐藏或通知里有多个不同金额时，需要手动补记。可随时在设置里关闭识别和系统授权。

独立账本与页面背景

  • 底栏点「账本 → 新建账本」，填写名称，选卡片颜色和图标。打开账本后，总览、明细、统计和新记账目都使用当前账本。原有内容保存在「主账本」。
  • 打开「更多 → 页面外观」选择照片、动图或视频，可在保存前预览。新壁纸默认按原图比例完整显示，浅色遮罩为 0%。图片比例和屏幕不同时，空余区域会显示底色；「铺满屏幕」可能裁切。其他页面默认跟随总览，每页可单独调整壁纸和卡片透明度。视频静音循环，优先选设备支持的 MP4。
  • 首页每 30 天显示备份提醒。完整 JSON 备份包含所有账本、凭证和背景，请保存到「文件」或网盘。大文件备份受设备内存和系统能力影响。

手机向下浏览时顶部栏自动收起，向上滚动时重新显示。iPhone 主屏幕版的顶部配色跟随壁纸。

日常记账提醒

第一次打开应用时可选择是否启用记账提醒。安卓安装版选择启用并允许系统通知后，会在 09:00、13:00、20:30 发送本机通知。内容会根据当天有没有记账或记过收入变化，锁屏上不显示金额。系统省电时提醒可能晚一些。

在「更多 → 日常记账提醒」修改三个时间或关闭。iPhone、iPad 和网页版可从同一入口下载日历文件，导入系统日历后由日历重复提醒。
